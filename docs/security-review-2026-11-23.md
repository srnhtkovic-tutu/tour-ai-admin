# Supabaseセキュリティ確認メモ（2026-11-23）

## 確認した事実

接続中のSupabaseプロジェクトで、`public.spots` について次を確認した。

- Row Level Security (RLS) が無効。
- `anon` ロールにSELECT、INSERT、UPDATE、DELETE、TRUNCATE等の権限が付与されている。
- `spots` に対するRLSポリシーは確認できなかった。

## リスク

匿名APIキーを持つクライアントから、スポット情報の読み取りだけでなく、追加・変更・削除等も可能になる構成である可能性が高い。

これはスポット情報の改ざん・削除につながるため、重要なセキュリティ確認事項として扱う。

## 今回変更していない理由

既存PWAが匿名ユーザーからどの操作を行っているか、またどの権限が必要かを確認せずに権限を変更すると、公開中アプリの表示・動作を壊す可能性がある。

そのため、今回のスポット収集再設計の変更には含めず、DB権限とPWAのアクセス方式を照合したうえで別途対応方針を決める。

## 次の確認事項

- PWAが`spots`へ直接行っている操作（SELECT/INSERT/UPDATE/DELETE）
- 公開ユーザーに必要な最小権限
- 管理画面の書き込みがEdge Function/RPC経由になっているか
- RLS有効化後の地域別アクセス制御
- 既存アプリの互換性テスト

**このメモは確認結果の記録であり、権限変更は実施していない。**
