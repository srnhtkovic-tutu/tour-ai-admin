# 旧版マイグレーション保管

このフォルダは、作業ブランチ作成時点で `supabase/migrations` に存在していた旧版SQLを、内容を変更せず保全するためのものです。

これらのファイルのバージョン番号は、現在接続されているSupabaseデータベースの `supabase_migrations.schema_migrations` に記録された適用済みバージョンとは一致しません。

**このフォルダ内のSQLを現在のSupabaseプロジェクトに再適用しないでください。**

旧版の内容は設計・実装経緯の参考として残します。現行DBの適用履歴は、別途データベースから取得した正確なマイグレーションSQLを `supabase/migrations` に保存します。
